This site is a static [Astro](https://astro.build) project hosted on Vercel. Every page is rendered to plain HTML at build time, and only a few small scripts run in the browser.

## Content as files

Projects, posts and work history live in [content collections](https://docs.astro.build/en/guides/content-collections/). Each project and post is a Markdown or MDX file, and work history is a single JSON file. A schema validates every entry at build time, so a missing title or a broken URL fails the build instead of shipping a half-empty page.

```ts
const projects = defineCollection({
  loader: glob({ base: './src/content/projects', pattern: '**/*.{md,mdx}' }),
  schema: ({ image }) =>
    z.object({
      title: z.string(),
      cover: image().optional(),
      featured: z.boolean().default(false),
    }),
});
```

Adding a project means adding a file. Hiding one means setting `draft: true`.

## Design

The palette is a warm off-white with a single soft tan accent, and the type is [Geist](https://vercel.com/font) and Geist Mono, self-hosted. Dark mode is a set of CSS variables swapped by a `data-theme` attribute, and the choice is remembered between visits. Every text colour pair is checked against WCAG AA contrast.

## Motion

Motion does three jobs: page changes, content entering the viewport, and feedback on hover.

- **Page transitions** use Astro's `<ClientRouter />` on top of the browser's View Transitions API. Project covers keep the same transition name on the card and the detail page, so a cover grows into place when you open a project.
- **Scroll reveals** are a CSS transition toggled by an `IntersectionObserver`, never a scroll listener.
- **The code editor** on the home page is highlighted with Shiki at build time, so the full code is in the HTML from the first paint. A small script splits it into characters and reveals them once, then stops.

All of it switches off when the operating system asks for reduced motion, and the content is fully visible without JavaScript.

## Performance

Images go through Astro's image pipeline, which outputs responsive WebP files at several widths. Fonts are preloaded, layout shift is reserved up front, and the only third-party script is privacy-friendly analytics.
