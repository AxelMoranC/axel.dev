## What it is

`article_list` is an input setting type for Shopify theme sections and blocks. It adds an article picker to the theme editor, so merchants can select multiple published articles from their store's blogs. Themes can use it for featured article sections, related content areas or article galleries.

It was [announced in the Shopify developer changelog](https://shopify.dev/changelog/posts/new-articlelist-input-setting-for-themes) on January 26, 2026, and is documented alongside the other [specialized input settings](https://shopify.dev/docs/storefronts/themes/architecture/settings/input-settings#article_list).

## How theme developers use it

A theme declares the setting in a section or block schema. The optional `limit` caps how many articles a merchant can pick, up to 50.

```json
{
  "type": "article_list",
  "id": "featured_articles",
  "label": "Featured articles",
  "limit": 12
}
```

In Liquid, the setting returns an array of `article` objects, so a section can loop over the merchant's selection:

```liquid
{% for article in section.settings.featured_articles %}
  <a href="{{ article.url }}">{{ article.title }}</a>
{% endfor %}
```

The array also supports the `paginate` tag and `.count`, and only published articles can be selected.
