## What it does

You describe a trip in plain English, for example "JFK to Tokyo mid-June under $1500, prefer nonstop", and the agent researches it on the live web. It returns a ranked shortlist of flights and hotels, each with a source link and the date the price was seen, so you can confirm before booking. It finds options; it doesn't book them.

## How it works

The CLI streams a single Claude request that has Anthropic's server-side `web_search` and `web_fetch` tools enabled, so the model can search, open pages and cite sources without any scraping code in the project. A detailed system prompt sets the research method and output format, and it is cached so repeated queries cost less.

While the agent works, a [Rich](https://github.com/Textualize/rich) live display shows a spinner with the current search or page being read, and an optional verbose mode streams summarized reasoning and every tool call. When it finishes, the answer renders as formatted Markdown with a usage summary.

Flags keep scope and cost under control:

| Flag | Purpose |
| --- | --- |
| `--flights-only` | Skip hotel research |
| `--hotels-only` | Skip flight research |
| `--max-searches N` | Cap the number of web searches |
| `--verbose` | Show reasoning summaries and tool events |

## Also a slash command

The same research instructions ship as a skill file, so the agent can run inside a coding assistant as `/travel-agent <query>` without the CLI.
