## What I built

A full-stack movie review application with a movie slideshow and user reviews. The React frontend talks to a REST API built with Spring Boot, which stores movies and reviews in MongoDB.

## How it fits together

- **Backend:** a Spring Boot service with separate controllers, services and repositories for movies and reviews. Reviews are created with a `POST` to `/api/v1/reviews` and linked to a movie by its IMDb ID.
- **Data:** MongoDB holds the movie and review documents through Spring Data repositories.
- **Frontend:** a React app with routing, a hero carousel of movies, embedded trailers and a review form, using Axios to call the API.
